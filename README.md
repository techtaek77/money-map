# 월급 계좌 지도 (money-map)

연금저축·IRP·ISA를 **어떤 순서로 열고, 무엇을 담는지** 10분 안에 설명하는 슬라이드와 월배당 시뮬레이터입니다.
설치 없이 브라우저에서 바로 열립니다.

## 슬라이드 넘기는 법

- 키보드 `←` `→` 또는 스페이스, 휴대폰은 좌우로 밀기
- 주소 끝에 `#7`을 붙이면 7번 장(비교표)부터 열립니다

## 기준과 고지

- 제도·세금 숫자는 **2026-07 확인 기준**입니다. ISA 한도 확대 등 개정안이 통과되면 달라집니다.
- ETF 이름과 종목코드는 2026-10 확인 기준이며 **매수 추천이 아니라 검색해 볼 이름**입니다.
- 시뮬레이터는 입력값에 따른 단순 계산이며 **투자 조언이 아닙니다**.
